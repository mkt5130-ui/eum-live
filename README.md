# 인천e음 실시간 참여 시스템

구성
- index.html : 참가자용
- live.html : 행사장 송출용
- admin.html : 관리자용

## 배포
GitHub 저장소의 Add file → Upload files에서 이 압축파일을 풀어 나온 파일들을 모두 업로드하세요.
그 다음 Settings → Pages → Deploy from a branch → main / (root) → Save.

예상 주소
- 참가자: https://mkt5130-ui.github.io/eum-live/
- LIVE: https://mkt5130-ui.github.io/eum-live/live.html
- 관리자: https://mkt5130-ui.github.io/eum-live/admin.html
